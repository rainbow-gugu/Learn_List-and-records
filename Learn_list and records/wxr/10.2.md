无重复字符的最长子串



class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        ans=l=0
        cnt=defaultdict(int) 有默认值的字典
        for r,c in enumerate(s):一个索引，一个对应的值
            cnt[c]+=1
            while cnt[c]>1://把前面的左窗口的移除
                cnt[s[l]]-=1
                l+=1
            ans=max(ans,r-l+1)
        return ans

语义缓存


**原理（3 步）**

1. 用户第一次提问：正常走 "检索→生成"，系统把 "问题 + 问题向量 + 答案" 存进缓存
2. 下一个人提问：先把新问题向量化，和缓存里的问题算相似度
3. 相似度超过阈值（如 0.95，判定是同一个问题）→ **直接返回缓存答案，不再调用大模型**；不超过才正常走流程
