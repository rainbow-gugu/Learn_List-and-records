1. **按文档结构分块**：利用标题、段落、列表、表格等结构切分（比如 Markdown 的 `#`、`##`，PDF 的章节）。金融研报有清晰的标题层级，这是最自然的切法；
2. **递归分块**（Recursive Character Text Splitter，LangChain 默认）：按分隔符优先级递归切 —— 先按段落，段落太长再按句子，句子太长再按字符，尽量在语义边界下刀；
3. **语义分块**（你说的方向）：把每个句子 / 小段算 embedding，计算相邻两段的相似度，**相似度骤降的地方就是语义边界**，在那里切。效果好但成本高（要多算很多 embedding）；
4. **按 token 数分块**（而不是字符数）：LLM 上下文按 token 计，中文字符和 token 数不一致（1 个中文字≈1–2 个 token），按 token 切更精准。



"什么是 embedding？为什么把文本变成向量之后，算余弦相似度就能找到语义相近的内容？"


embedding 是把文本映射到高维向量（项目里 1024 维）。模型训练时让语义相近的文本在向量空间中方向接近。检索时用余弦相似度比的是两个向量的**方向**（不是距离），值越接近 1 越相似，因为它不受文本长短影响。
